# 代码结构

## 训练入口

`main.py` 负责参数解析、数据加载、模型创建、训练、验证和测试。主要函数如下：

| 函数 | 作用 |
|---|---|
| `parse_option()` | 读取数据集、模型、训练轮数和 batch size 等参数 |
| `set_loader()` | 创建训练、验证与测试 DataLoader |
| `set_model()` | 创建模型，并为普通骨干或 MUSCLE 选择相应损失 |
| `train()` | 执行一轮训练 |
| `validate()` | 计算验证或测试指标 |

主程序在训练过程中保存最佳 checkpoint，训练结束后在测试集上计算 Accuracy、Sensitivity、Specificity、Precision、F1-score、Cohen's Kappa 和混淆矩阵。

## 数据读取

`datasets/` 包含 APTOS、Chaoyang、CheXpert、ISIC 2018 Task 3 和 KvasirV2 的数据读取与增强代码。各数据集通常由 `*_dataset.py` 和 `augmentation.py` 两部分组成，分别负责样本划分、图像读取、标签处理与训练增强。

原始实现中的数据根目录使用 `/home/datasets/...`，训练 DataLoader 默认设置 `num_workers=32`。这套配置面向 Linux 服务器；在 Windows 环境运行时需要重新指定数据路径，并根据硬件调整 worker 数量。

## 网络结构

`networks/net_factory_cls.py` 根据 `args.model` 创建网络。普通骨干与对应的 MUSCLE 模型分别为：

| 普通骨干 | MUSCLE 版本 |
|---|---|
| `ResNet` | `ResNet_CHW_SAFS_TMSL` |
| `VanillaNet` | `VanillaNet_CHW_SAFS_TMSL` |
| `SwinTransformer` | `SwinTransformer_CHW_SAFS_TMSL` |

以 `ResNet_Multi_Scale.py` 为例，`SpatialAttention` 计算空间注意力，`FeatureSqueeze` 沿指定轴压缩特征，`EvidenceCollector` 将压缩后的特征转换为各类别的非负 evidence，`TMSL` 收集并聚合不同尺度的 evidence。`ResNet_CHW_SAFS_TMSL` 将这些模块与预训练 ResNet 组合起来。

第二阶段通过以下代码冻结骨干网络：

```python
for p in self.original_net.parameters():
    p.requires_grad = False
```

## 损失与指标

普通骨干使用交叉熵损失。MUSCLE 的 `get_loss()` 同时计算聚合 evidence 与各尺度 evidence 的分类损失，并加入尺度间的冲突约束。相关实现位于 `losses/losses.py`。

`utils.py` 负责指标计算与结果保存。医学图像数据常有明显的类别不平衡，因而本仓库的轻量实验同时报告 Accuracy、Macro-F1 与混淆矩阵。

## 主要调用关系

```text
main.py
  ├─ set_loader()          数据集与 DataLoader
  ├─ set_model()           网络与损失函数
  │    └─ net_factory()    根据参数选择模型
  ├─ train()               前向计算、反向传播与参数更新
  └─ validate()            验证、测试与指标保存
```
