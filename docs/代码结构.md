# 代码结构：从原作者实现到三数据集复现入口

## 两套入口的关系

仓库保留原作者的 `main.py`，用于呈现论文代码原貌；本 fork 的实际复现实验使用 `experiments/paper_resnet50/`。后者没有重写 MUSCLE 算法，而是围绕原有 ResNet、MAFC、证据分支和损失函数补齐 Windows 路径、稳定数据划分、数据审计、两阶段 checkpoint、自动续跑和结果留存。

`experiments/dermamnist_resnet18/` 是项目早期的 CPU smoke test。它证明了最小两阶段链路可以运行，但不再代表当前成果的主要层级。

## 正式数据入口

`experiments/paper_resnet50/__main__.py` 提供四个子命令：

| 子命令 | 作用 |
|---|---|
| `validate-data` | 生成稳定 manifest，检查文件、标签、类别分布、解码、重复与跨划分重复 |
| `benchmark` | 用少量 step 测量 baseline 和 MUSCLE 的时间与显存，决定统一短轮配置 |
| `run` | 运行 baseline 或 MUSCLE，保存 checkpoint、日志、指标和混淆矩阵 |
| `analyze-uncertainty` | 复用 MUSCLE checkpoint，分析四尺度 uncertainty、错误预测和高斯噪声响应 |

`data.py` 负责三套数据的确定性划分和图像读取。KvasirV2 与 APTOS 的原作者 loader 依赖 `os.listdir` 顺序，本入口改为稳定排序并把实际文件清单写入 manifest；ISIC 2018 使用官方 train、validation 和 test 划分。

`engine.py` 负责模型创建、训练、验证、指标、checkpoint 与冻结检查。第一阶段的 ResNet-50 使用 ImageNet-1K V2 权重；第二阶段加载 baseline 最佳权重后，只有 MAFC、EvidenceCollector 与融合相关模块参与更新。

`uncertainty.py` 使用公开实现中的 `u = K / sum(evidence + 1)`，记录聚合与四个尺度的逐样本不确定性，并在 0–255 像素空间加入论文所列方差的高斯噪声。

## 原作者核心实现

| 论文环节 | 代码位置 |
|---|---|
| 原始训练、验证与测试流程 | `main.py` |
| 数据读取与增强 | `datasets/` |
| 模型选择 | `networks/net_factory_cls.py` |
| ResNet 多尺度实现 | `networks/classification/ResNet_Multi_Scale.py` |
| VanillaNet 多尺度实现 | `networks/classification/VanillaNet_Multi_Scale.py` |
| Swin Transformer 多尺度实现 | `networks/classification/SwinTransformer_Multi_Scale.py` |
| 证据分类损失与尺度约束 | `losses/losses.py` |
| 原始指标与结果保存 | `utils.py` |

以 ResNet 为例，`ResNet_CHW_SAFS_TMSL` 从 `layer1` 至 `layer4` 取得多尺度特征。`SpatialAttention` 和 `FeatureSqueeze` 完成多轴压缩，`EvidenceCollector` 输出非负 evidence，`TMSL` 汇总四个尺度。

第二阶段在模型内部把 backbone 参数设为 `requires_grad=False`。复现实验还额外比较训练前后的参数和 BatchNorm buffers，避免只检查梯度而漏掉运行统计量变化。

## 实际调用链

```text
validate-data
  → 扫描完整数据
  → 稳定划分与 manifest
  → 解码、标签、重复和交叉检查

run --stage baseline
  → ImageNet 预训练 ResNet-50
  → 训练与验证
  → 保存 last.ckpt 和 best ACC 权重
  → 完整测试指标

run --stage muscle
  → 加载 baseline 最佳权重
  → 冻结 original_net
  → 四尺度 MAFC 与 evidence
  → 聚合 evidence 和证据损失
  → 保存 checkpoint、指标与机制检查

analyze-uncertainty
  → 重新加载 MUSCLE 最佳权重
  → 干净测试集精确回放
  → 四尺度 uncertainty
  → 五个高斯噪声等级
  → 逐样本 CSV、汇总 JSON 和图表
```

## 输出与公开边界

本入口把完整结果写到仓库之外。每次运行保存解析后的配置、Git SHA、依赖、GPU、manifest 哈希、checkpoint 哈希、epoch 日志、逐类指标、混淆矩阵和中文结论。公开仓库只提交脱敏的汇总结果，不提交原始图像、权重、逐样本路径或完整日志。
