# 实验范围与设置

## 论文设置

论文在 ISIC 2018、APTOS 2019、KvasirV2、Chaoyang 和 CheXpert 五套数据上评估 MUSCLE，主要使用 ResNet50、VanillaNet5 与 Swin-T。输入尺寸为 256×256，骨干网络使用 ImageNet-1K 预训练权重。第一阶段训练 500 个 epoch，第二阶段训练 200 个 epoch；优化器为 SGD，并采用 poly 学习率策略。论文实验运行在 NVIDIA RTX A6000 上。

## 本仓库的轻量实验

轻量实验使用 DermaMNIST-64 与 ResNet18，在 CPU 上验证两阶段流程。训练集、验证集和测试集分别抽取 224、70 与 140 个样本，baseline 和 MUSCLE 各训练 3 个 epoch。

| 项目 | 论文主要设置 | 轻量实验 |
|---|---|---|
| 数据 | 五套医学图像数据集 | DermaMNIST-64 子集 |
| 骨干 | ResNet50、VanillaNet5、Swin-T | ResNet18 |
| 输入尺寸 | 256×256 | 256×256 |
| 第一阶段 | 500 epoch | 3 epoch |
| 第二阶段 | 200 epoch | 3 epoch |
| 硬件 | NVIDIA RTX A6000 | CPU，4 线程 |
| 优化器 | SGD | SGD |
| 初始学习率 | 0.01 | 0.01 |
| momentum | 0.9 | 0.9 |
| weight decay | ResNet、VanillaNet 为 0.0001；Swin-T 为 0.001 | 0.0001 |

## 已验证内容

实验完成了 baseline 训练与 checkpoint 重新加载、MUSCLE checkpoint 加载、骨干网络冻结、四尺度 evidence 输出、融合模块梯度与参数更新，以及测试集指标计算。

DermaMNIST 不属于论文使用的五套数据，ResNet18 也不是论文主要表格中的 ResNet50。训练数据量和 epoch 数差异更大。因此，这项实验属于代码流程验证，结果不与论文表格进行数值比较。

运行结果见 [`experiments/dermamnist_resnet18/RESULTS.md`](../experiments/dermamnist_resnet18/RESULTS.md)。
