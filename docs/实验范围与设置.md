# 实验范围与设置：论文配置与本次复现的边界

## 本次实验为什么采用 10+5 epoch

论文在五套医学图像数据上评估 MUSCLE，主要使用 ResNet-50、VanillaNet-5 与 Swin-T。第一阶段训练 500 epoch，第二阶段训练 200 epoch，运行硬件为 NVIDIA RTX A6000。

本次工作的目标是在 RTX 5060 Laptop GPU 上建立可信、可重复且计算量可控的正式数据链路。KvasirV2 benchmark 显示三套数据能够在一天内统一完成 10+5 epoch，因此没有再降到 5+3，也没有让不同数据集使用不同轮数。

| 项目 | 论文主要设置 | 本次三数据集复现 |
|---|---|---|
| 数据集 | ISIC、APTOS、KvasirV2、Chaoyang、CheXpert | KvasirV2、ISIC 2018、APTOS 2019 |
| 数据量 | 完整数据 | 三套均使用完整数据 |
| 骨干 | ResNet-50、VanillaNet-5、Swin-T | ResNet-50 |
| 输入尺寸 | 256×256 | 256×256 |
| 预训练 | ImageNet-1K | ImageNet-1K V2 ResNet-50 |
| 第一阶段 | 500 epoch | 10 epoch |
| 第二阶段 | 200 epoch | 5 epoch |
| 优化器 | SGD + poly | SGD + poly |
| 初始学习率 | 0.01 | 0.01 |
| momentum | 0.9 | 0.9 |
| weight decay | ResNet 为 0.0001 | 0.0001 |
| batch size | 16 | 16 |
| 随机种子 | 论文未形成公开多种子复现记录 | 1234，单一种子 |
| 硬件 | NVIDIA RTX A6000 | RTX 5060 Laptop GPU，8 GB |
| 精度 | 论文公开设置 | AMP |

训练轮数是当前结果与论文数值之间最大的差异。三套数据的 MUSCLE 指标均略低于对应 baseline，不能据此否定论文方法，也不能因为部分绝对指标接近 Table IV 就声称完成数值复现。

## 数据划分与审计

KvasirV2 按每类 70%/10%/20% 形成 5,600/800/1,600 个样本；APTOS 2019 按类别分层形成 2,563/366/733 个样本。两者均使用稳定排序生成 manifest，避免 `os.listdir` 顺序在不同机器上改变划分。ISIC 2018 直接使用官方 train/validation/test，样本数为 10,015/193/1,512。

数据审计检查了文件存在性、标签范围、类别分布、全部图像解码、内容哈希、重复内容和跨划分重复。三套数据均无损坏文件、无跨划分重复；KvasirV2、ISIC 和 APTOS 分别发现 12、2 和 128 组划分内重复内容。这些重复没有跨越训练、验证和测试边界，因此审计通过，但在解释结果时仍应保留记录。

## 两阶段验收

每套 baseline 的最佳 ACC 权重都被 MUSCLE 第二阶段逐键加载。训练门禁不仅检查 `requires_grad=False`，还比较训练前后的 backbone 参数与 BatchNorm buffers。三套数据均满足：

- 四个尺度的 evidence 形状与类别数一致；
- evidence 非负；
- backbone 全部参数冻结；
- backbone 参数和 buffers 未变化；
- 融合模块参数发生更新；
- baseline 与 MUSCLE checkpoint 均可重新加载；
- 测试集未发生类别坍缩。

## 不确定性实验

推理实验不更新参数，直接加载 MUSCLE 最佳 checkpoint。干净测试集指标与训练阶段保存的结果精确一致。每张测试图像分别使用高斯噪声方差 0、10、100、1000 和 10000 推理，并保存聚合与四尺度 uncertainty。

验收不要求所有噪声等级严格单调，因为短轮模型和有限样本都可能产生局部波动。报告同时保留均值、中位数、Spearman 相关、最高噪声与干净数据差值，以及以 uncertainty 区分错误预测的 AUROC。

## 尚未覆盖的范围

当前工作没有运行 Chaoyang 和 CheXpert，也没有覆盖 VanillaNet-5、Swin-T、多随机种子、完整 500+200 epoch、消融实验、统计显著性、模型校准和 Grad-CAM。Chaoyang 需要单独申请且原划分逻辑存在需要确认的细节；CheXpert 数据规模和训练成本明显更高。

因此，合适的结论是“三套论文数据集上的 ResNet-50 全量短轮复现与机制验证已经完成”。不合适的结论是“论文已被完整复现”或“已证明 MUSCLE 在本机设置下优于 baseline”。

详细指标见 [三数据集短轮复现结果](三数据集短轮复现结果.md)。
