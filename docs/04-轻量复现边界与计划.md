# 轻量复现边界与后续计划

## 为什么不直接完整复现

论文正式实验使用五套医学图像数据、ResNet50 等骨干网络、256×256 输入和较长训练。

论文给出的主要训练设置包括：

- 第一阶段 500 个 epoch；
- 第二阶段 200 个 epoch；
- ImageNet-1K 预训练权重；
- NVIDIA RTX A6000；
- SGD 优化器和 poly 学习率策略。

这不适合作为刚开始学习 Python 和深度学习时的第一个运行目标。数据下载、环境兼容、训练时间和显存都会显著增加困难。

## 当前准备的轻量材料

本机准备了：

- DermaMNIST-64；
- ResNet18 官方预训练权重；
- 项目专用 CPU Python 环境；
- 数据完整性和普通 ResNet18 前向检查。

DermaMNIST 不属于论文五套数据，ResNet18 也不是论文主要表格中的 ResNet50。因此这条路线只能用于验证方法流程。

数据和权重只保存在本机，不上传 GitHub。

## 第一目标：3+3 epoch smoke test

第一阶段：

```text
DermaMNIST-64
→ ResNet18 baseline
→ 训练 3 个 epoch
→ 保存 checkpoint
→ 重新加载并验证
```

第二阶段：

```text
加载第一阶段 checkpoint
→ 创建 ResNet18 + MUSCLE
→ 冻结骨干网络
→ 训练 3 个 epoch
→ 检查骨干参数未更新
→ 检查 MAFC/证据模块参数发生更新
```

最低输出：

- 运行命令和参数；
- 随机种子；
- 训练和验证损失；
- Accuracy；
- macro-F1；
- 混淆矩阵；
- checkpoint；
- 运行时间；
- 失败和修改记录。

这个阶段成功后，可以表述为：

> 在 DermaMNIST-64 和 ResNet18 上跑通了 MUSCLE 的两阶段轻量方法流程。

不能表述为：

> 已复现 MUSCLE 论文结果。

## 第二目标：20+10 epoch 短训练

如果 smoke test 成功，再尝试：

```text
baseline 20 epoch
MUSCLE 10 epoch
batch size 8
固定随机种子
```

这一阶段观察的是：

- MUSCLE 与 baseline 的指标趋势；
- macro-F1 是否改善；
- 类别不平衡时少数类是否改善；
- 不确定性是否随噪声增加而上升；
- 训练时间和显存占用。

短训练结果仍属于代理数据实验。

## 第三目标：论文数据正式最小复现

只有轻量流程稳定后，再考虑下载论文中的一套数据。

KvasirV2 相对结构清楚、每类样本数一致，可以作为候选；但压缩数据仍有约 GB 级体积。是否下载应根据存储、网络和训练资源另外决定。

正式复现需要对齐：

- 数据版本和划分；
- 输入尺寸和增强；
- 骨干网络深度；
- 预训练权重；
- 优化器和学习率；
- 两阶段训练轮数；
- 评价指标；
- 随机种子和重复次数。

未完成这些对齐前，不应拿轻量结果直接与论文表格比较。
