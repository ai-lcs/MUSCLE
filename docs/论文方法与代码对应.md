# 论文方法与代码对应：MUSCLE 的证据链

## 从多尺度特征到最终判断

MUSCLE 的出发点是：骨干网络不同阶段保留的信息并不相同。浅层具有更高空间分辨率，能够保留纹理和局部结构；深层具有更强的语义表达。ResNet 版本通过 `need_layer_name_list` 选择 `layer1` 至 `layer4`，让四个阶段分别形成一份分类 evidence。

| 论文内容 | 主要代码位置 | 本次复现中的检查 |
|---|---|---|
| 多尺度特征提取 | `ResNet_Multi_Scale.py` | 四个尺度均被调用 |
| Multi-Axis Feature Compression | `SpatialAttention`、`FeatureSqueeze` | 融合相关参数能够更新 |
| 分类 evidence | `EvidenceCollector` | 四个输出形状正确且非负 |
| 多尺度聚合 | `TMSL.forward()` | 聚合输出维度正确 |
| Dirichlet 证据损失 | `losses/losses.py` | 第二阶段可前向、反向并收敛 |
| 两阶段 checkpoint | `ResNet.py`、实验入口 | baseline 权重逐键加载成功 |
| backbone 冻结 | `ResNet_CHW_SAFS_TMSL` | 参数和 BatchNorm buffers 均未变化 |
| uncertainty 分析 | `uncertainty.py` | 正误预测、尺度与噪声实验 |

## Multi-Axis Feature Compression

Multi-Axis Feature Compression（MAFC）沿通道 C、高度 H 和宽度 W 三个方向处理特征。公开代码通过 `permute()` 交换张量轴，使同一组注意力与压缩逻辑分别作用在三个方向。压缩后的表示拼接后进入证据网络。

这一步的作用不是简单地把四个特征图相加，而是先让每个尺度形成结构一致、可用于分类 evidence 的表示。三轴处理是 MUSCLE 区别于普通多尺度池化的重要组成部分。

## Evidence、Dirichlet 参数与 uncertainty

`EvidenceCollector` 使用 Softplus 保证 evidence 非负。损失函数以

```text
alpha = evidence + 1
```

构造 Dirichlet 参数。若类别数为 `K`，总强度为 `S = sum(alpha)`，整体不确定性为

```text
u = K / S
```

总 evidence 增加时，`S` 增大，`u` 随之降低。这里的 evidence 是分类模型内部的支持量，不能解释为临床诊断证据，也不能仅凭 uncertainty 数值推断模型已经完成校准。

三数据集推理结果表明，错误预测的平均 uncertainty 均高于正确预测，以 uncertainty 区分错误预测的 AUROC 为 0.7363–0.8197。这说明 evidence 强度包含与错误风险相关的信息，但尚未进行 ECE、Brier score 或温度缩放等概率校准实验。

## 多尺度 evidence 的聚合

`TMSL.forward()` 先让四个尺度分别产生 evidence，再按公开实现逐步平均：

```python
evidence_a = evidences[0]
for i in range(1, len(evidences)):
    evidence_a = (evidences[i] + evidence_a) / 2
```

论文从 opinion 与 Dirichlet 参数的角度描述多尺度聚合。两份 evidence 的平均可以对应两份 `alpha=evidence+1` 的平均；当尺度多于两个时，连续两两平均会受到聚合顺序影响。当前仓库准确记录并复现公开代码的行为，不把“公开代码与论文表述是否完全等价”提前写成已经解决的问题。

## 两阶段训练

第一阶段训练普通 ResNet-50 并保存最佳分类 checkpoint。第二阶段创建 `ResNet_CHW_SAFS_TMSL`，把该 checkpoint 加载为 `original_net`，随后冻结 backbone，只训练 MUSCLE 新增模块。

```text
完整训练数据
  → ResNet-50 baseline
  → best ACC checkpoint
  → ResNet-50 + MUSCLE
  → 冻结 backbone 参数和 buffers
  → 训练 MAFC、evidence 与融合模块
```

公开仓库没有提供论文实验对应的第一阶段 checkpoint。本次复现因此为每套数据独立完成 baseline，并记录输入 checkpoint 的 SHA-256，避免把普通 ImageNet 权重误当成 MUSCLE 第二阶段所需的分类 checkpoint。

## 当前实验对论文机制的支持程度

ISIC 2018 和 APTOS 2019 的四尺度平均 uncertainty 随网络阶段加深而下降，与论文关于深层特征更确定的观察一致。KvasirV2 的前三个尺度接近最大 uncertainty，第四尺度明显较低，说明短轮训练下最终决策主要依赖深层分支，尚未形成更平滑的尺度差异。

噪声实验中，三套数据在方差 10000 时均出现 ACC 下降和平均 uncertainty 上升。APTOS 完整呈现均值与中位数的单调趋势；ISIC 的均值符合、但中位数存在波动；KvasirV2 只在高噪声区间明显上升。因此可说当前结果“部分支持”论文 Fig. 4、Fig. 6–7 的机制观察，不能表述为完全复现相关图中的全部统计趋势。
