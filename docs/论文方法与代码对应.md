## 多尺度特征

MUSCLE 将骨干网络不同阶段的输出视为不同尺度的特征。ResNet 版本默认提取 `layer1` 至 `layer4`。浅层特征具有较高的空间分辨率，保留较多纹理和局部信息；深层特征的语义表达更强。`need_layer_name_list` 用于指定参与融合的阶段。

## Multi-Axis Feature Compression

Multi-Axis Feature Compression（MAFC）沿通道 C、高度 H 和宽度 W 三个方向处理特征。代码通过 `permute()` 交换张量轴，使 `SpatialAttention` 与 `FeatureSqueeze` 可以复用于三个方向。压缩后的结果在拼接后送入证据网络。

## Evidence 与不确定性

`EvidenceCollector` 使用 Softplus 输出非负 evidence。损失函数以

```text
alpha = evidence + 1
```

构造 Dirichlet 分布参数。若类别数为 K，Dirichlet 强度为 `S = sum(alpha)`，代码中的整体不确定性可写为 `u = K / S`。这里的 evidence 指模型对各类别的内部支持量，并非临床意义上的医学证据。

## 证据聚合

`TMSL.forward()` 先为每个尺度计算 evidence，再进行逐步平均：

```python
evidence_a = evidences[0]
for i in range(1, len(evidences)):
    evidence_a = (evidences[i] + evidence_a) / 2
```

连续两两平均三个以上尺度时，数值结果会受到聚合顺序影响。公开代码中的这一实现与论文对意见聚合的表述之间是否完全等价，是后续分析中需要单独核对的问题。

## 两阶段训练

第一阶段训练普通的 ResNet、VanillaNet 或 Swin Transformer，并保存分类 checkpoint。第二阶段创建相应的 MUSCLE 版本，加载第一阶段参数并冻结 `original_net`，只训练 MAFC 与证据分支。

```text
普通骨干训练
  → 保存 checkpoint
  → 创建 MUSCLE 模型并加载 checkpoint
  → 冻结骨干参数
  → 训练多尺度压缩与证据融合模块
```

仓库未提供论文实验所用的第一阶段 checkpoint，因此正式复现需要先完成普通骨干训练。
