# 代码结构导读：每个文件夹负责什么

## 总体目录

```text
MUSCLE/
├─ datasets/
│  ├─ APTOS/
│  ├─ Chaoyang/
│  ├─ CheXpert/
│  ├─ ISIC_2018_Task_3/
│  └─ Kvasir/
├─ losses/
│  ├─ AutomaticWeightedLoss.py
│  └─ losses.py
├─ networks/
│  ├─ classification/
│  └─ net_factory_cls.py
├─ main.py
└─ utils.py
```

## `main.py`：程序总入口

`main.py` 负责把数据、模型、损失和训练过程串起来。

主要部分包括：

- `parse_option()`：读取数据集、模型、训练轮数、batch size 等参数；
- `set_loader()`：创建训练、验证和测试 DataLoader；
- `set_model()`：创建模型并选择普通交叉熵或证据损失；
- `train()`：执行一轮训练；
- `validate()`：验证模型并计算指标；
- 主程序：创建结果目录、循环训练、保存 checkpoint，最后在测试集上评估。

目前默认参数不是为 Windows 初学者设计的：

```text
dataset = CheXpert
model = ResNet_CHW_SAFS_TMSL
model_deep = 50
epochs = 200
batch_size = 16
```

训练 DataLoader 使用 `num_workers=32`。在 Windows 笔记本上直接使用这个值可能启动失败或消耗大量资源。

## `datasets/`：数据读取和图像增强

每套数据通常包含两个文件：

```text
XXX_dataset.py
augmentation.py
```

`XXX_dataset.py` 负责：

- 找到图像和标签；
- 按训练、验证、测试划分样本；
- 读取图像；
- 返回模型需要的张量和标签。

`augmentation.py` 负责训练阶段的数据增强，例如裁剪、翻转、旋转、颜色变化、模糊、噪声和遮挡。

五套读取代码目前都把数据目录写成 Linux 风格的 `/home/datasets/...`。这意味着仓库下载下来后不能自动找到本机数据。

## `networks/net_factory_cls.py`：模型选择器

`net_factory(args)` 根据 `args.model` 创建模型。

普通骨干：

```text
ResNet
VanillaNet
SwinTransformer
```

对应的 MUSCLE 模型：

```text
ResNet_CHW_SAFS_TMSL
VanillaNet_CHW_SAFS_TMSL
SwinTransformer_CHW_SAFS_TMSL
```

如果 CUDA 可用，模型会被移动到 GPU；多张 GPU 时会使用 `DataParallel`。

## `networks/classification/`：模型主体

这个目录包含三类骨干网络和它们的多尺度版本。

以 `ResNet_Multi_Scale.py` 为例，最值得先看的类是：

| 类 | 作用 |
|---|---|
| `SpatialAttention` | 通过池化、卷积和 Sigmoid 找到更重要的区域 |
| `FeatureSqueeze` | 从一个方向压缩特征 |
| `EvidenceCollector` | 将压缩特征转换成各类别的非负证据 |
| `TMSL` | 收集多个尺度证据并逐步聚合 |
| `ResNet_CHW_SAFS_TMSL` | 把冻结的 ResNet、MAFC 和证据融合组合起来 |

代码中有：

```python
for p in self.original_net.parameters():
    p.requires_grad = False
```

这对应论文第二阶段的“冻结骨干网络”。

## `losses/losses.py`：训练目标

普通骨干网络使用 `CrossEntropyLoss`。

MUSCLE 使用 `get_loss()`，它大致包含：

- 聚合意见的证据分类损失；
- 每个尺度的证据分类损失；
- 不同尺度之间的冲突或一致性损失。

现阶段不需要推导 Gamma、Digamma 和 KL 散度。先记住三个目的：分类要正确、错误类别不要积累过多证据、多个高置信尺度不要严重冲突。

## `utils.py`：指标和结果保存

这里计算并整理：

- Accuracy；
- Sensitivity；
- Specificity；
- Precision；
- F1-score；
- 多分类 Cohen's Kappa；
- 混淆矩阵和逐样本结果 CSV。

医学数据经常类别不平衡，因此不能只看 Accuracy。后续轻量实验至少应报告 Accuracy、macro-F1 和混淆矩阵。
