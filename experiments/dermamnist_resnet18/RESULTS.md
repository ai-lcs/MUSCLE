## 数据子集

实验采用固定随机种子分层抽样，并保留原始数据的不平衡分布。

| 类别编号 | 训练 | 验证 | 测试 |
|---:|---:|---:|---:|
| 0 | 7 | 2 | 5 |
| 1 | 11 | 3 | 7 |
| 2 | 25 | 8 | 15 |
| 3 | 3 | 1 | 2 |
| 4 | 25 | 8 | 15 |
| 5 | 150 | 47 | 94 |
| 6 | 3 | 1 | 2 |
| 合计 | 224 | 70 | 140 |

类别 5 约占各子集的三分之二，类别 3 和类别 6 在测试集中各有 2 个样本。小样本与类别不平衡会使宏平均指标产生较大波动。

## 测试结果

| 模型 | Accuracy | Macro-Sensitivity | Macro-Specificity | Macro-Precision | Macro-F1 |
|---|---:|---:|---:|---:|---:|
| ResNet18 baseline | 0.6500 | 0.2023 | 0.8930 | 0.1456 | 0.1665 |
| ResNet18 + MUSCLE | 0.6714 | 0.1429 | 0.8571 | 0.0959 | 0.1148 |

MUSCLE 的测试集平均 uncertainty 为 0.5003。

### Baseline 混淆矩阵

```text
[[0, 0, 1, 0, 0,  4, 0],
 [0, 0, 4, 0, 0,  3, 0],
 [0, 0, 8, 0, 0,  7, 0],
```

### MUSCLE 混淆矩阵

```text
[[0, 0, 0, 0, 0,  5, 0],
 [0, 0, 0, 0, 0,  7, 0],
 [0, 0, 0, 0, 0, 15, 0],
 [0, 0, 0, 0, 0,  2, 0],
 [0, 0, 0, 0, 0, 15, 0],
 [0, 0, 0, 0, 0, 94, 0],
 [0, 0, 0, 0, 0,  2, 0]]
```

MUSCLE 将 140 个测试样本全部预测为类别 5。其 Accuracy 比 baseline 高 0.0214，但 Macro-F1 低 0.0517，说明 Accuracy 的变化来自多数类比例，不能据此判断模型性能有所改善。

## Windows 路径兼容性处理

首次运行在第二阶段加载 checkpoint 时失败。原始实现通过 `eval()` 拼接路径，Windows 路径中的 `\v` 被 Python 解释为控制字符。实验脚本在调用原模型前将 checkpoint 路径转换为正斜杠：

```python
checkpoint_path.resolve().as_posix()
```

该处理位于新增实验入口中，未修改上游核心文件。

## 结果范围

本次实验验证了 MUSCLE 两阶段代码链路在 DermaMNIST-64、ResNet18 和 CPU 环境下可以运行。它没有复现论文使用的数据集、骨干规模、训练轮数和硬件设置，也没有观察到优于 baseline 的性能结果。
